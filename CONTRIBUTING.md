Guía de contribución – Tienda TECSUP

¡Gracias por tu interés en colaborar con Tienda TECSUP!

Este documento contiene las indicaciones para reportar errores, proponer mejoras y enviar cambios al proyecto.

## 1. Reportar errores

Si encuentras un error en el funcionamiento de la tienda, sigue estos pasos:

1. Ingresa al apartado Issues del repositorio.
2. Selecciona New Issue.
3. Escribe un título claro que describa el problema.
4. Explica qué esperabas que ocurriera y qué ocurrió realmente.
5. Indica el archivo donde encontraste el error.
6. Describe los pasos para reproducirlo.

## 2. Proponer mejoras

Si deseas agregar una nueva funcionalidad o mejorar el proyecto:

1. Describe la mejora que deseas implementar.
2. Explica por qué sería útil para la tienda.
3. Indica qué archivos podrían modificarse.
4. Espera la revisión de la propuesta antes de realizar cambios importantes.

## 3. Proceso de colaboración

Para colaborar en el proyecto se recomienda:

1. Crear un fork del repositorio.
2. Clonar el repositorio en la computadora.
3. Crear una rama con un nombre descriptivo.
4. Realizar los cambios necesarios.
5. Comprobar que todo funcione correctamente.
6. Registrar los cambios mediante un commit.
7. Enviar los cambios con un Pull Request.

## 4. Checklist antes de enviar un Pull Request

Antes de enviar una contribución, verifica lo siguiente:

- [ ] El código funciona correctamente.
- [ ] Los cambios realizados están relacionados con la propuesta.
- [ ] No se modificaron archivos innecesarios.
- [ ] Se probaron las funcionalidades modificadas.
- [ ] El commit tiene un mensaje descriptivo.
- [ ] El Pull Request explica los cambios realizados.
- [ ] Se menciona el número del Issue relacionado.

## 5. Recomendaciones

- Mantener un código ordenado y fácil de comprender.
- Utilizar nombres descriptivos para las variables y funciones.
- Revisar los cambios antes de publicarlos.
- Mantener una comunicación respetuosa con los colaboradores.

## 6. Nombres de ramas

Se recomienda utilizar nombres descriptivos para las ramas, por ejemplo:

- fix-total-carrito
- mejora-diseno
- actualizar-documentacion
